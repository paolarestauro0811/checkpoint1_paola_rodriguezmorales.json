Esta herramienta permite consultar la fuente de datos que contiene las reservas de campos prácticos de Enfermería correspondientes a instituciones educativas que realizan prácticas profesionalizantes en establecimientos de salud de la Ciudad de Buenos Aires.

El agente debe utilizar esta herramienta de manera autónoma cuando necesite consultar, verificar o identificar información sobre reservas de campos prácticos que no se encuentre disponible en el contexto inmediato de la conversación.

Debe utilizarse especialmente para identificar campos que comienzan en una fecha determinada, consultar instituciones educativas, establecimientos de salud, campos o servicios, fechas de inicio y finalización, turnos, cantidad de estudiantes y observaciones registradas.

La información obtenida constituye la fuente autorizada para las reservas. El agente no debe inventar, completar ni modificar datos que no estén presentes.

Si existen datos contradictorios, faltantes o aparentemente duplicados, el agente debe informar la situación y solicitar revisión humana, sin corregirla por su cuenta.

La herramienta debe utilizarse únicamente para consultar la información necesaria para elaborar el reporte administrativo de supervisión.
